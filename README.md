# RN-01 // CLASSIFIED TERMINAL

A cinematic, interactive web experience built specifically for Raj Nandani.

## Core Vibe
- Deep cyberpunk / classified file aesthetic
- Subtle glitch / horror-thriller atmosphere
- Pure vanilla HTML/CSS/JS (No heavy frameworks)
- Fully responsive on mobile
- Audio synthesis (optional toggle)

## Deployment
This project is configured to deploy instantly on **Vercel**.
It includes the `@libsql/client` (Turso) dependency and an `api/status.js` endpoint to easily attach a Turso database in the future.

### Local Development
You can just open `index.html` in your browser. No build steps required.
